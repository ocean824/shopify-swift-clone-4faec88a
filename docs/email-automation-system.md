## 🧠 STEP 1 — CORE SEGMENTS

### Segment Overview Table

| Segment | Psychology | Core Desire | Primary Objection | Monetization Goal |
|---------|-----------|-------------|-------------------|-------------------|
| **Cold Subscribers** | Curious but skeptical. Downloaded freebie, evaluating quality. | "Will this actually help me make better beats?" | "I've downloaded stuff before that was trash" | Convert to first purchase ($19-29) |
| **First-Time Buyers** | Validated interest. Testing product quality. | "Did I make the right choice? What else is there?" | "I don't want to buy something I won't use" | Second purchase within 30 days |
| **Repeat Buyers** | Trust established. Active producers. | "I want the complete toolkit without overpaying" | "Is the bundle worth it vs. buying individually?" | Bundle/subscription conversion |
| **Power Buyers** | Invested. Serious about craft. | "Give me everything. I want to be unstoppable." | "Already have so much—do I need more?" | Lifetime Pantheon membership |
| **Pantheon Members** | VIP mentality. Want insider access. | "Keep me ahead of everyone else" | "Am I actually using this enough?" | Retention + referrals + upsells |
| **Dormant Users** | Life got busy. Lost momentum. | "I want to get back into producing" | "I've fallen off—starting again feels hard" | Re-engagement + win-back offer |
| **Content-Only** | Learners first. Collectors second. | "Teach me, don't sell me" | "Stop pushing products" | Soft ascension via education |

## ✉️ STEP 2 — EMAIL ARCHETYPES

### Email Type Definitions

| Type | Purpose | Feels Like | Never Sounds Like |
|------|---------|------------|-------------------|
| **Authority** | Position as expert. Teach advanced concepts. | "A mentor dropping gems" | Generic tips from ChatGPT |
| **Value** | Give free tools, workflows, templates | "Found gold in my inbox" | Thin content with hidden pitch |
| **Story** | Build connection. Share real journey. | "This person gets it" | Fabricated humble-brag |
| **Offer** | Present product with clear value | "This solves my exact problem" | Discount spam |
| **Soft Pitch** | Educate then contextual CTA | "Oh, they have this too?" | Bait and switch |
| **Hard Pitch** | Scarcity, deadlines, urgency | "I need to act now" | Fake urgency manipulation |
| **Reactivation** | Pattern interrupt, curiosity | "Wait, what did I miss?" | Guilt trip |
| **Ascension** | Move up product ladder | "This is the next logical step" | Pushy upgrade pressure |

## 💰 STEP 4 — HORMOZI VALUE STACKING

### Product Ladder

```
FREE TIER ($0)
├── Free sample pack (lead magnet)
├── Email tips series
└── YouTube/social content

LOW TICKET ($19-29)
├── Single kit (samples, drums, MIDI)
└── Entry point → trust builder

MID TICKET ($49-79)
├── 3-pack bundles
├── Themed collections
└── Proves value → ready for more

HIGH TICKET ($149-199)
├── All Kits Bundle
├── Complete producer toolkit
└── Maximum value extraction

LIFETIME ($500)
├── Pantheon Membership
├── Everything forever
├── Monthly new drops
└── Community + collabs
```

---

### Value Stack Formula (Per Offer)

Every offer email must include:

1. **The Core Product** - What they're buying
2. **The Accelerator Bonus** - Saves time (templates, presets)
3. **The Skill Bonus** - Teaches technique (video tutorials)
4. **The Insider Bonus** - Exclusive access (early drops, community)
5. **Risk Reversal** - Guarantee or easy refund
6. **Urgency Driver** - Real scarcity (limited quantity, time, price)

**Example Stack:**
> "Get the Stained Glass Vol. 2 Kit ($29)
> + FREE: Mixing template used on these loops ($19 value)
> + FREE: 15-min breakdown video of every loop ($47 value)
> + FREE: Early access to next 3 drops (Priceless)
> Total Value: $95+ → You pay: $29
> 100% satisfaction guarantee. Keep the bonuses even if you refund."

---

### Scarcity Principles (Non-Manipulative)

| Type | When to Use | How to Communicate |
|------|-------------|-------------------|
| **Quantity** | Limited collabs, exclusive drops | "Only 100 copies of this collab kit" |
| **Time** | Launch windows | "Price increases Friday at midnight" |
| **Access** | Pantheon/VIP | "Not sold separately after this" |
| **Bonuses** | Launch bonuses | "Bonuses removed after launch week" |

**Never:** Fake countdown timers, artificial "selling out," manufactured urgency

## ⚙️ STEP 5 — AUTOMATION ARCHITECTURE

### Shopify Flow Automations

These can be set up directly in Shopify:

| Trigger | Action | Segment |
|---------|--------|---------|
| Customer created | Tag "cold_subscriber" | Cold |
| First order | Tag "first_time_buyer", remove "cold_subscriber" | First-Time |
| 2nd order | Tag "repeat_buyer" | Repeat |
| Order > $100 | Tag "power_buyer" | Power |
| Specific product (Pantheon) | Tag "pantheon_member" | Pantheon |
| No order in 60 days | Tag "dormant" | Dormant |

### n8n Workflow Sequences

#### Workflow 1: Welcome Sequence (Cold Subscribers)
```
Trigger: New subscriber tag added
→ Day 0: Welcome + freebie delivery
→ Day 2: Quick win tip
→ Day 4: Story email
→ Day 7: Free resource
→ Day 10: Soft pitch
→ Day 14: Offer email
→ Exit to weekly nurture
```

#### Workflow 2: Post-Purchase Sequence (First-Time)
```
Trigger: First order completed
→ Day 0: Order confirmation + quick start guide
→ Day 2: How to use tutorial
→ Day 5: Bonus content unlock
→ Day 10: Complementary product soft pitch
→ Day 14: Bundle preview
→ Exit to repeat buyer nurture
```

#### Workflow 3: Ascension Sequence (Repeat → Power)
```
Trigger: 3rd order completed
→ Day 1: "You're in the top 10%" recognition
→ Day 3: Exclusive bundle offer
→ Day 7: Pantheon preview
→ Day 14: Limited-time Pantheon pitch
```

#### Workflow 4: Dormant Win-Back
```
Trigger: No open/purchase in 60 days
→ Day 0: "Still producing?" pattern interrupt
→ Day 3: Free resource (no pitch)
→ Day 7: Story email
→ Day 14: Win-back offer (15% off)
→ Day 21: Final sunset email
→ If no engagement: Unsubscribe
```

#### Workflow 5: Pantheon Onboarding
```
Trigger: Pantheon purchase
→ Day 0: Welcome to the inner circle
→ Day 1: Full access guide
→ Day 3: Community introduction
→ Day 7: First exclusive drop
→ Ongoing: Weekly insider email
```
